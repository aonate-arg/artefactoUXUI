# Capturas de evidencia

Acá van las capturas que referencia `assets/capturas.js` y que usa cada hallazgo
del tablero. Los nombres tienen que coincidir exactamente.

| Archivo | Qué tiene que mostrar |
|---|---|
| `01-home-escritorio.png` | La home completa en escritorio |
| `02-home-movil.png` | La home en móvil de 375 px, con el pie a la vista |
| `03-pedir-sin-local.png` | `/pedir` al entrar, con el mensaje «No hay productos en el menú» |
| `04-dialogo-direccion.png` | El diálogo «Ingresa dirección de entrega», abierto |
| `05-locales.png` | El listado de los ocho locales |
| `06-pie-de-pagina.png` | El pie de página, con la columna «Mi cuenta» |
| `07-foco-teclado.png` | Un control del encabezado con el foco puesto con Tab |
| `08-menu-productos.png` | El catálogo de productos, con las categorías a la vista |

Ninguna captura debe superar los 300 KB. Mientras falten, el tablero muestra un
bloque «Captura pendiente» con el nombre del archivo que espera, y la medición
de cada hallazgo lo sostiene igual.
